# dissokin

Release kinetics fitting for in vitro dissolution data, with model selection
by information criteria and bootstrap uncertainty on the quantities that get
interpreted mechanistically.

The package exists because of a habit in the formulation literature: eight
release models are fitted to a profile of six to ten points, the one with the
highest R-squared is declared the mechanism, and no interval is reported for
anything. This repository implements the fitting properly and then measures,
by simulation against known ground truth, how often that habit gives the wrong
answer.

## What is in here

    dissokin/models.py       eight release models as a common interface
    dissokin/fitting.py      least squares fitting, AIC/AICc/BIC, bootstrap
    dissokin/similarity.py   f1 and f2 with a vessel level bootstrap
    dissokin/simulate.py     data generating processes with known truth
    examples/                the three simulation experiments and the figures
    tests/                   unit tests, including analytic checks
    paper/                   LaTeX technical report
    results/                 JSON output of each experiment

## Models

Zero order, first order, Higuchi, Korsmeyer-Peppas, Hixson-Crowell, Weibull,
Hopfenberg and Baker-Lonsdale. Baker-Lonsdale is implicit in the released
fraction and is inverted by a vectorised bisection rather than by the usual
linearisation. See `dissokin/NOTES.md` on the Hopfenberg and Hixson-Crowell
overlap.

## Quick use

```python
import numpy as np
from dissokin import fit_all, mechanism_with_uncertainty

t = np.array([0.25, 0.5, 1, 2, 4, 6, 8, 12])          # hours
q = np.array([15.1, 21.8, 30.4, 42.1, 57.9, 68.0, 75.2, 88.4])   # percent

for r in fit_all(t, q)[:3]:
    print(f"{r.model:18s} R2={r.r2:.4f}  dAICc={r.delta_aicc:5.2f}  "
          f"w={r.akaike_weight:.3f}  {r.params}")

print(mechanism_with_uncertainty(t, q, n_boot=2000))
```

`fit_all` returns results ranked by AICc with Akaike weights attached, so a
profile that does not distinguish between two models reports two comparable
weights instead of a single winner.

## Reproducing the study

```
pip install numpy scipy matplotlib pytest
python -m pytest tests -q
python examples/01_selection_study.py     # model selection, ~12 min
python examples/02_mechanism_study.py     # Peppas exponent, ~20 min
python examples/03_f2_study.py            # f2 decisions, ~2 min
python examples/make_figures.py
cd paper && latexmk -pdf report.tex
```

Every random draw is seeded, so the numbers in the report regenerate exactly.

## Scope and honesty

The experiments use simulated data, deliberately. The question asked here is
how often an estimator recovers the truth, and that cannot be measured on real
profiles, where the truth is unknown. Noise levels, sampling schedules and
release extents are set to the ranges reported in the formulation literature,
but no claim is made about any particular real formulation, and no
experimental data are included.

## Reproducibility

Every number in the report is generated by the code in this repository rather
than asserted. `examples/make_report_numbers.py` reads the stored JSON results
and writes them into the LaTeX source as macros, so the text cannot drift away
from the data it describes. Every random draw is seeded, so re-running the
experiments reproduces the reported figures exactly.
