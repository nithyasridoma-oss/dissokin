Notes for talking about this project
====================================

These are the questions an interviewer or a supervisor is most likely to ask.
Read them before the interview. If you cannot answer one of them in your own
words, do not put that part of the project forward.

**In one sentence, what did you do?**
I tested whether the standard way of choosing a drug release model from a
dissolution profile actually works. It mostly does not, and I measured by how
much.

**Why does R-squared fail?**
R-squared can never go down when you add a parameter to a model. So comparing
a one-parameter model such as Higuchi against a two-parameter model such as
Korsmeyer-Peppas on R-squared is not a fair comparison: the richer model wins
almost by construction. Information criteria such as AICc add an explicit
penalty for each parameter, so they can prefer the simpler model.

**What is AICc and why the small sample correction?**
AIC estimates the expected out-of-sample prediction error, and equals
n ln(RSS/n) + 2(k+1) for least squares with unknown constant variance. The
extra +1 counts the error variance, which is also estimated. AICc adds a
correction that matters when the number of data points is small relative to
the number of parameters. With six sampling points and two parameters, the
correction term is larger than the penalty it corrects, so leaving it out
would be wrong here.

**What is an Akaike weight?**
The relative likelihood of each model in the set, normalised to sum to one. It
is the honest output when two models fit almost equally well, because it says
"0.55 and 0.42" instead of naming a winner.

**What did the numbers actually say?**
Selecting by R-squared recovered the true model in roughly a third of
simulated profiles. AICc recovered it in about three quarters. The two rules
disagreed on about two thirds of individual profiles. On data generated by
pure Higuchi diffusion, R-squared named Korsmeyer-Peppas almost every time.

**Where is AICc worse?**
On data generated by Korsmeyer-Peppas with n near 0.42, AICc often preferred
the one-parameter Baker-Lonsdale model, because a simpler model approximates
that curve closely enough that the second parameter is not worth its penalty.
An information criterion identifies the simplest model the data support, not
physical truth. I report that in the paper rather than hiding it.

**Why bootstrap the Peppas exponent?**
Because a mechanism is assigned by comparing n against fixed boundaries, 0.45
and 0.89 for a slab, and the gap between them is only 0.44 wide. If the 95
percent interval for n is of similar width, the label is not supported by the
data. A residual bootstrap refits the model to resampled residuals a few
thousand times and gives that interval directly, with no distributional
assumption about the parameter.

**Residual bootstrap or case bootstrap?**
Residual, because the sampling times are fixed by the protocol, not random.
Resampling whole time points would change the design. The package implements
both, and the case version is there for when the residuals are clearly not
identically distributed.

**Why the 60 percent cutoff?**
The Korsmeyer-Peppas power law is derived for the early stage of release and
is conventionally applied only below about 60 percent released. Applying it
honestly is important, because it is what leaves a two-parameter model with
only four to six points.

**Why is the log-log fit a problem?**
Fitting ln Q against ln t is not the same as fitting Q. The log transform
reweights the points, giving the early low readings the most leverage, which
is exactly where the relative assay error is largest. If the assay error is
roughly constant in percent released, the linearised estimate is biased.

**Why simulated data and not real data?**
Because the question is how often the method recovers the truth, and the truth
is unknown for real profiles. This is a study of the estimator, not of a
formulation. The limitation is that the noise model is an assumption; real
dissolution error is heteroscedastic and correlated within a vessel, which
would make the intervals wider, so these results are optimistic.

**What would you do next?**
Add a heteroscedastic noise model and within-vessel correlation, then repeat.
Add profile likelihood intervals for n as a cross-check on the bootstrap.
Validate against real profiles from a laboratory where the formulation is well
characterised, to check that the fitted parameters are sensible even though
recovery cannot be scored.

**Is this your Master's thesis?**
No, and do not let anyone assume it is. The M.Pharm dissertation was the
in-situ gel work; this is a separate project done afterwards, on my own. Keep
the two clearly apart, because the CV lists both and an interviewer will
notice if the story moves.

**If asked directly whether you used AI tools**
Answer honestly. Most employers now expect that tools were used somewhere and
care only that the person can explain and defend the work. Denying it and then
being unable to answer one of the questions above is the bad outcome, not the
tool use.
